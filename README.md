# miniLojaFrontEnd

Front-end da **MiniLoja** (Angular 17, standalone components + signals).

O projeto fica em [`MiniLojaFrontEnd/`](MiniLojaFrontEnd). Veja o [README do projeto](MiniLojaFrontEnd/README.md) para rodar, a arquitetura e a lista de telas, e o [planejamento](MiniLojaFrontEnd/PLANEJAMENTO-FRONT.md) para as decisões de design e API.

```bash
cd MiniLojaFrontEnd
npm ci
npm start   # http://localhost:4200 (API simulada por padrão)
```
